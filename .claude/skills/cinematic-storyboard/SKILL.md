# Cinematic Storyboard Maker --- Production Standard v2.0

## Purpose

Create a visual planning artifact, not a screenplay. Do not invent
dialogue or write a full script unless requested. Optimize for
repeatability, geometry, continuity, legibility, and professional
usefulness---not merely a pretty image.

## Priority order

1.  Exact 4:3 panel geometry.
2.  Character and location continuity from supplied references.
3.  Consistent handmade drawing style.
4.  Strong, readable composition.
5.  Accurate and legible production annotations.
6.  Decorative polish.

## Hard geometry rules

-   Every individual drawing panel must be exactly **4:3 (1.333333:1)**.
    This is not a requirement for the overall page; it is a requirement
    for each panel.
-   Never use 16:9 panels, stretch a panel, or claim the panels are 4:3
    based on the page dimensions.
-   Generate or design each panel on a 4:3 canvas before assembly.
    Example exact dimensions: 1200 × 900 px.
-   Keep production notes in a separate area beneath or beside the image
    panel; do not include the notes area when measuring the drawing.
-   Do not crop away important content just to force the ratio.
    Recompose or regenerate instead.
-   Use a fixed layout template for the page. For 16 frames, default to
    a 4 × 4 grid with consistent margins, gutters, header, panel sizes,
    and note zones.
-   Verify each panel's image rectangle mathematically when tools are
    available. If verification is not possible, do not claim exact
    verification.
-   If a single image-generation prompt cannot reliably enforce the
    layout, generate the panels separately and assemble them
    programmatically or with a fixed template.

## Workflow

1.  Parse the brief: title, description, frame count, emotion,
    characters, location, cameras, lenses, references, constraints.
2.  Load the approved master storyboard image, character references,
    location/light references, and written style specification.
3.  Plan each panel before generating: ID, action, composition, shot
    size, camera angle, movement, lighting, emotional purpose,
    equipment, optional sound cue.
4.  Generate individual panels in 4:3 using the same master style
    reference and character references. Keep the stable style prompt
    unchanged; vary only the panel-specific action and composition.
5.  Assemble panels into a fixed layout. Keep the header, margins,
    gutters, image boxes, annotation zones, and typography consistent.
6.  Run the quality rubric and geometry checks. Fix failures before
    presenting as final.
7.  Deliver the board and briefly describe what changed. Do not write a
    screenplay unless requested.

## Master visual style

Desired: - Handmade director's storyboard; loose graphite, pencil,
charcoal, and ink. - Visible sketch marks, imperfect contours,
expressive hatching and smudges. - Clearly illustrated, not
photorealistic or a photograph with a pencil filter. - Mostly black,
white, and graphite grey, with restrained blue-grey, muted green, faded
ochre, or subdued amber washes. - Strong shadows, selective highlights,
readable silhouettes, atmospheric depth. - Rough but purposeful: action
and composition must remain clear. - Consistent treatment across every
panel.

Avoid: - Photorealism, glossy concept art, 3D rendering, polished
digital painting, oversaturated colors. - A different drawing style in
every panel. - Excessive detail that obscures the composition. -
Decorative effects that compete with the shot information.

**Consistency rule:** use a reusable master style image and stable style
prompt. Written descriptions alone are not enough to ensure consistent
visual results.

## Character continuity

-   Use the supplied character images as the primary source for facial
    structure, hairstyle, body proportions, skin tone, clothing, and
    equipment.
-   Prefer the latest reference when appearance has changed.
-   Keep characters recognizable but illustrated.
-   Do not put character names on panels or notes unless requested.
-   If identity is hard to preserve, simplify facial detail while
    retaining silhouette, hairstyle, proportions, and clothing.

## Header and annotations

At the top include: project title; one- or two-line visual description;
prototype/version; frame count; explicit note **"4:3 EACH FRAME"**;
camera package if known.

Each panel has a 4:3 image area plus a separate annotation area. Use
compact, legible notes: - SHOT / ACTION - CAM (camera body) - LENS -
SIZE / ANGLE - MOVE - LIGHT - SOUND (optional)

Keep notes technically plausible. Do not invent equipment if the user
has not confirmed it. Legibility is more important than simulating
handwriting.

## Shot coverage

Choose shots to serve the project. When relevant, vary: - Establishing
wides with rule of thirds and negative space. - Mediums,
over-the-shoulder, profile, silhouettes. - Close-ups and extreme
close-ups. - High angle/top-down, low angle/contra-plongée, and
selective Dutch angles. - POV / subjective shots. - Environmental
inserts and visible light in the location. - Tactile details: hands,
equipment, clothing, impact, sweat, breath. - Preparation, recovery, and
quiet personal moments. - Static shots and motivated movement.

Do not force every shot type into every board. Avoid repetitive centered
medium shots.

Storyboards are visual mood/camera explorations, not a finalized script.

## Quality rubric

Score each category 0--2: 0 = fail, 1 = revise, 2 = pass.

  -----------------------------------------------------------------------
  Category                            Pass criteria
  ----------------------------------- -----------------------------------
  Geometry                            Every image panel is exactly 4:3;
                                      no stretching or harmful cropping

  Drawing style                       Clearly handmade
                                      graphite/charcoal/ink, not
                                      photorealistic

  Character continuity                Matches supplied references

  Composition                         Clear focal point, intentional
                                      placement, readable action

  Shot variety                        Meaningful range of sizes and
                                      angles

  Lighting                            Direction, contrast, and
                                      environment are visible

  Notes                               Camera, lens, size/angle, movement,
                                      and light noted where relevant

  Legibility                          Drawings and notes readable at
                                      normal size

  Layout                              Stable header, grid, gutters,
                                      margins, annotation zones

  Project continuity                  Correct look, equipment, and
                                      constraints
  -----------------------------------------------------------------------

**Release gate:** Geometry must score 2. No category may score 0. Target
at least 17/20. Never claim a check was performed unless it was actually
performed.

## Technical verification

-   Inspect final dimensions.
-   Measure each drawing rectangle separately from its annotation zone.
-   Confirm width ÷ height = 4 ÷ 3.
-   Check panel count, layout, notes, stretching, cropping, and readable
    action.
-   Prefer integer dimensions divisible by 4 and 3, such as 1200 × 900
    px per drawing panel.
-   If assembled programmatically, calculate panel boxes from exact
    integer dimensions.

## Iteration protocol

When the user requests changes: 1. Identify the failing dimension:
geometry, style, character, composition, annotations, or layout. 2.
Preserve all approved elements. 3. Change only the failing panel or
element where possible. 4. Do not restart the whole board unless asked.
5. Re-run the same rubric. 6. State what changed and disclose remaining
limitations. 7. Keep a brief version history: version/date, reference
used, changes, known issues, next step.

## Final checklist

-   [ ] Requested panel count is present.
-   [ ] Every individual drawing is exactly 4:3.
-   [ ] Notes occupy a separate area and are legible.
-   [ ] Style matches the master reference and is clearly hand-drawn.
-   [ ] Character appearance matches references.
-   [ ] Shot sizes and angles vary meaningfully.
-   [ ] Lighting is intentional and visible.
-   [ ] Camera annotations fit the known equipment.
-   [ ] Project-specific constraints are followed.
-   [ ] No unsolicited screenplay/dialogue.
-   [ ] Unverified properties are described honestly.

## Core principle

Do not ask one image-generation prompt to solve illustration, identity,
typography, panel geometry, and page layout at once. Plan shots,
generate panels, assemble the page with a fixed template, and verify the
result. **The repeatable process---not more adjectives---is the route to
consistent quality.**
